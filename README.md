# Tax Tracker — สำหรับใบยืนยันการซื้อขายของ Dime

เว็บที่ลากไฟล์ PDF ใบยืนยันการซื้อขาย (Confirmation Note) เข้าไป แล้วได้กำไร/ขาดทุนที่รับรู้แล้ว
แบบ FIFO รายปี พร้อมตัวเลขสำหรับยื่นภาษีของหุ้นต่างประเทศ

ไฟล์ถูกอ่านในเบราว์เซอร์เท่านั้น ไม่มี server ไม่มี database ไม่มีการอัปโหลดไปที่ไหน

---

## ⚠️ รองรับเฉพาะเอกสารของ Dime เท่านั้น

โปรแกรมนี้อ่าน **ใบยืนยันการซื้อขายจาก บล. เคเคพี ไดม์ (KKP Dime)** เท่านั้น
เพราะตัวอ่านถูกเขียนจากตำแหน่งของตัวอักษรในเทมเพลตของ Dime โดยตรง

เอกสารจากโบรกเกอร์อื่น (Settrade, Liberator, InnovestX, IBKR ฯลฯ) **จะถูกปฏิเสธ**
พร้อมข้อความว่า "ยังไม่รองรับรูปแบบเอกสารนี้" — ไม่ใช่บั๊ก แต่เป็นการตั้งใจไม่เดา
เพราะการเดาโครงสร้างเอกสารภาษีผิดอันตรายกว่าการไม่รับ

### ไฟล์ที่ใช้ได้

| ชื่อไฟล์ขึ้นต้นด้วย | คืออะไร | ใช้ทำอะไร |
|---|---|---|
| `Dime_offshore_confirmationNote_*` | ซื้อขายหุ้น/ออปชันต่างประเทศ | ✅ คำนวณภาษี |
| `Dime_th_stock_confirmationNote_*` | ซื้อขายหุ้นไทย | ✅ ดูผลงาน (ได้รับยกเว้นภาษี) |
| `Dime_mutual_fund_confirmationNote_*` | ซื้อขายกองทุนรวม | ✅ ดูผลงาน (ได้รับยกเว้นภาษี) |
| `Dime_monthly_statement_*` | สรุปรายเดือน | ⚠️ ใช้ตรวจว่าเอกสารครบไหม เท่านั้น |

**สรุปรายเดือนใช้คำนวณภาษีไม่ได้** เพราะบอกแค่ยอดคงเหลือสิ้นเดือน ไม่มีรายการซื้อขายทีละรายการ
แต่ใส่เข้ามาด้วยเถอะ — ระบบจะเอาไปเทียบว่ามีใบยืนยันหายไปเดือนไหนบ้าง

---

## เอาไฟล์มาจากไหน

ในแอป Dime → **บัญชีของฉัน → เอกสารและรายงาน** แล้วดาวน์โหลด

1. **Confirmation Note** ทุกใบ ย้อนหลังให้ไกลที่สุดเท่าที่มี
2. **Monthly Statement** ทุกเดือน (แนะนำ — ช่วยหาว่าใบไหนหาย)

> **ดาวน์โหลดย้อนหลังให้ครบที่สุด** ถ้าคุณขายหุ้นที่ซื้อมาก่อนใบยืนยันใบแรกที่มี
> ระบบจะหาต้นทุนไม่เจอ และกันยอดขายนั้นออกจากตัวเลขภาษี พร้อมบอกว่าต้องไปตามใบไหน

ไฟล์ของ Dime **ใส่รหัสผ่านไว้** ให้กรอกรหัสในช่องบนหน้าเว็บก่อนลากไฟล์
(รหัสเดียวใช้กับทุกไฟล์ได้)

## เริ่มใช้

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:5173 → ลากไฟล์ PDF ทั้งโฟลเดอร์เข้าไปได้เลย

ถ้าไฟล์เยอะ (200+) จะใช้เวลาหลายนาที มีแถบความคืบหน้าและปุ่มยกเลิก
ผลจะทยอยขึ้นระหว่างทาง ไม่ต้องรอจนจบ

### ใช้จาก command line (ไม่ต้องเปิดเว็บ)

วางไฟล์ไว้ในโฟลเดอร์ `dime_pdf/` แล้วสร้างไฟล์ `.password.local` ใส่รหัสผ่านบรรทัดเดียว

```bash
npm run scan -- dime_pdf --csv    # อ่านทุกไฟล์ สรุปผล เขียน data/orphans.csv
npm run reconcile                 # เทียบยอดกับสรุปรายเดือน หาว่าใบไหนหาย
npm test                          # ชุดทดสอบ
```

`npm run scan` จะขึ้น `FAIL` ถ้าอัตราผ่านการตรวจสอบตัวเลขต่ำกว่า 95% — ใช้เป็นด่านกันของพังได้

## อ่านตัวเลขยังไง

หน้า **ภาษี** แสดง 3 ตัวเลขแยกกัน อย่าเอามาบวกกัน

| ตัวเลข | คืออะไร |
|---|---|
| **กำไร/ขาดทุนสุทธิ** | รวมทุกอย่าง กำไรหักขาดทุน — ใช้ดูว่าลงทุนได้ผลแค่ไหน |
| **รวมเฉพาะรายการที่กำไร** | นับเฉพาะรายการที่ขายได้กำไร ไม่หักขาดทุน — **ตัวนี้คือตัวที่เกี่ยวกับภาษี** |
| **รวมเฉพาะรายการที่ขาดทุน** | แสดงไว้ให้เห็นครบ ถึงจะเอาไปหักกลบไม่ได้ |

สองตัวแรกไม่เท่ากันเพราะตัวที่สองไม่ได้เอาขาดทุนไปหักออก

**คำนวณภาษีเฉพาะหุ้นต่างประเทศ** (รวมออปชัน) ส่วนหุ้นไทยและกองทุนรวมไทยได้รับยกเว้น
จึงแสดงเป็นผลงานอย่างเดียว

### ป้ายที่ต้องสังเกต

- 🟠 **กรอกเอง** — รายการที่พิมพ์เข้าไปเอง ไม่ได้มาจากเอกสาร หน้าภาษีจะบอกด้วยว่ากำไรกี่ % พึ่งตัวเลขพวกนี้
- 🔴 **ต้องตรวจสอบ** — แถวที่ตัวเลขในเอกสารบวกลบไม่ลงตัว ระบบไม่แก้ให้ ไม่ทิ้ง แค่ติดธงไว้
- ⚠️ **ยอดขายที่ไม่มีต้นทุน** — ขายไปแล้วแต่หาใบซื้อไม่เจอ ถูกกันออกจากตัวเลขภาษีทั้งหมด

## ใบยืนยันหาย ทำยังไง

Dime ไม่ได้ส่งใบยืนยันมาทุกรายการ ถ้าเจอกรณีนี้:

1. ใส่ **Monthly Statement** เข้าไปด้วย → หน้าภาพรวมจะบอกว่า symbol ไหนเริ่มไม่ตรงเดือนไหน
2. กลับไปโหลดใบยืนยันของเดือนนั้นจากแอป Dime
3. ถ้าหาไม่เจอจริงๆ → กด **"กรอกต้นทุนเอง"** ที่หน้านำเข้า ฟอร์มจะเติมข้อมูลที่รู้อยู่แล้วมาให้
   เหลือกรอกแค่วันที่กับราคา

รายการที่กรอกเองต้องเปิด **"เก็บข้อมูลไว้ในเบราว์เซอร์นี้"** ไม่งั้นหายตอนรีเฟรช

## เรื่องความเป็นส่วนตัว

- ไม่มี server ไม่มี database ไม่มี analytics ไม่มีฟอนต์จาก CDN
- Content Security Policy ตั้ง `connect-src 'self'` — **ยิงข้อมูลออกไม่ได้แม้โค้ดจะเขียนพลาด**
- ไม่มี `console.log` ข้อมูลส่วนตัวแม้ตอน dev
- **ตรวจสอบเองได้:** เปิด DevTools → แท็บ Network → ลากไฟล์เข้าไป → ดูว่าไม่มี request ออกไปไหนเลย

ถ้าจะ fork ไปใช้เอง: `.gitignore` กัน `*.pdf`, `dime_pdf/`, `samples/`, `data/`, `.password.local` ไว้แล้ว
**อย่าเอาออก** และอย่า commit เอกสารจริงเด็ดขาด

## ข้อจำกัดที่ควรรู้

- **ไม่รองรับ OCR** ไฟล์สแกนหรือรูปถ่ายอ่านไม่ได้ ต้องเป็น PDF ต้นฉบับจากแอป
- **ไม่รู้เรื่อง corporate action** ถ้ามีหุ้นแตกพาร์หรือปันผลเป็นหุ้น ต้นทุน FIFO จะเพี้ยน
  ระบบจะเตือนเมื่อเจอสัญญาณ (ขายเกินจำนวนที่ถือ) แต่ไม่ปรับให้เอง
- **ไม่มีราคาตลาด** ที่ยังถืออยู่แสดงแค่ต้นทุน ไม่มีกำไรที่ยังไม่รับรู้ เพราะไม่ดึงข้อมูลจากภายนอก
- **ออปชันที่หมดอายุ** ไม่มีใบยืนยันตอนหมดอายุ ต้องบันทึกเองถ้าอยากให้ครบ
- **หุ้นรางวัล (REW)** ปัจจุบันไม่ถูกนับเป็นต้นทุนและไม่นับเป็นเงินได้
- **ใช้ FIFO อย่างเดียว** แยกตามบัญชีและหลักทรัพย์ ไม่มีวิธีคำนวณต้นทุนแบบอื่น

ความถูกต้องขึ้นกับความครบถ้วนของเอกสารที่นำเข้า
